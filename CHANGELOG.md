# Changelog

## 0.1.1

- Examples come with the package: Settings › Packages › 3D Printing › Examples opens them. This needs
  verknode's node API 1.1.
- Dependencies: scipy, networkx and lxml, which trimesh needs for bodies, hulls, watertight checks and 3MF
  files.

## 0.1.0

- The first release. It has:
  - mesh and CAD readers and writers (STL, OBJ, PLY, OFF, 3MF, GLB/glTF, STEP, IGES, BREP, DXF);
  - modelling, a slicer and G-code;
  - 3D viewers and an editor on the canvas.
